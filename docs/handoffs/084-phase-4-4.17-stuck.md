## Gotchas

- **4.17's root cause** (lessons `[4.17]`; a2's commit `a4fed0c` body):
  - With `--pdf-engine=typst` (bare), pandoc extracts media to `<cwd>/media-<hash>/` and writes relative `./media-…` paths into the `.typ` file. That works.
  - With any other spelling, pandoc extracts to `/tmp/media-…` and writes `/tmp/…`. This includes an absolute path and even a `./typst` symlink. Typst resolves that path against its root (the cwd), never finds it, and pandoc exits 43.
  - It reproduces with the container's own pinned pandoc and typst, so it is not a sidecar artifact.
  - The one-workflow document has no image, so 4.17's e2e was green. Only Michael's condition, an export of the image-bearing `essay-fixture.md`, exposed it.
- **The viable fix shape** (a2/a3 both name it):
  - keep `--pdf-engine=typst` literal, so `pandoc_args`, `buildPandocArgs` and their 9 tokens stay as they were at `phase/4`;
  - prepend the sidecar's directory (the existing `typst_sidecar_path(exe_dir)`'s parent rule) to the `PATH` of the spawned pandoc `Command`.
  - Check that tauri-plugin-shell 2.3.6's `Command` exposes `.env`/`.envs` in the installed crate, and whether `.envs` replaces or extends the environment.
  - On Windows the directory is already searched first, so prepending is harmless.
  - The PATH separator is `;` on Windows; use `std::env::join_paths`.
- **Reusable from `task/4.17`:**
  - `typst_sidecar_path` and its four layout tests;
  - the `commands.rs` `current_exe` parent lookup;
  - the `shell_scope.rs` doc sentence;
  - step 7's error-aware wait.
  - Not reusable: the `pdfEngine` TS option and the absolute-token `pandoc_args` change, which revert to the bare `typst`.
- **Michael's condition still applies.** The PATH lookup is by name, so `typst` must be exactly that name in the dev, `deps`, `.app` and `usr/bin` layouts.
- **Add an image-bearing e2e or Rust-level export guard.** The gap is that the one-workflow export had no image: a container export through the extracted `.deb` pandoc over `essay-fixture.md` with a shadowing typst first on the outer PATH must exit 0 with `pdfimages -list` showing 2 images.
