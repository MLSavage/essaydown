## Findings (≤ 20, most severe first)

1. **should-fix** — packages/editor/src/schema.ts:94 — Omitting all DOM parse rules makes the editor's own clipboard round-trip discard structure and marks. Required. In `/report/paste.cjs`, load `# Heading\n\n**bold**\n`, select all in PM, copy, then paste over the same selection: `/report/paste.log` becomes `Heading\n\nbold\n`. The native ProseMirror clipboard path already exists despite the comment saying it does not. Fix: provide DOM parse rules paired with the schema's DOM serialization, preserving supported attributes and opaque atom values, and add browser tests for self-copy/paste of headings, marks, lists and raw nodes. Never turn an opaque node's displayed text into executable HTML.

2. **should-fix** — apps/desktop/src/dev/DevEditor.tsx:92 — Raw CodeMirror coordinates are passed directly to a map of canonical Markdown, so a source edit that changes canonical line layout moves the next rendered edit. Required. `/report/source-cursor.cjs` enters `alpha\n\n\n\nbeta`, moves the cursor before `beta` (confirmed offset 0), toggles and types `X`; actual output is `alpha\n\nbetaX\n`, expected `alpha\n\nXbeta\n`. Fix: map the cursor from the live source document through its parsed node/offset into the rendered document, or explicitly translate raw coordinates to canonical coordinates before using cursorMap. Add cases for extra blank lines and noncanonical heading/list spellings without adding an undo entry.

3. **should-fix** — packages/editor/src/toggle.ts:233 — Character offsets ignore escaping and continuation prefixes, so even canonical source receives the cursor at the wrong character. Required. `/report/probe.log`: in canonical `a\*b c`, PM position 3 (before `b`) maps to source ch 2 (before `*`) instead of ch 3; in `> alpha\n> beta gamma`, the position before `beta` maps to line 2/ch 0 rather than ch 2. Fix: retain character-level offset transformations from serialization and invert those transformations for source-to-rendered mapping. Assert independently derived character locations; a round-trip through two mutually wrong functions, or an in-bounds check, is insufficient.

4. **should-fix** — packages/core/src/positions.ts:353 — Deriving undispatched table ranges solely from descendant spans cannot map empty cells or a wholly empty row. Required. The table `| a | b |\n| - | - |\n| | |\n` leaves three unresolved paths in `/report/probe.log`; this is the shape produced by packages/editor/src/input.ts:179, not unsupported input. Fix: instrument table layout so every cell, including empty cells, has an explicit range/anchor, and each row includes its layout extent. Test empty first/middle/last cells and cursor toggling from the newly created empty body row.

5. **should-fix** — apps/desktop/src/dev/DevEditor.tsx:72 — The measured 10,000-word typing path exceeds the phase's 16 ms p95 budget. Required reconciliation follow-up. `/report/latency.cjs` loads 100 paragraphs of 100 words, types 120 real keyboard characters, discards 20 warmups and measures beforeinput to the next timer task after input/observer work: p95 **38.6 ms**, repeated **39.5 ms**. This is Linux headless Chromium on a shared host, includes scheduling and dev-mode costs, and does not measure guaranteed paint or isolate one function. Fix: insert the follow-up required by task 1.10; profile the real route under a documented measurement protocol and reduce repeated full-document work. In particular, cache the subscription's formatted snapshot by root identity rather than serializing on every snapshot read, then remeasure before claiming the budget met.

6. **should-fix** — packages/editor/src/store.ts:170 — Ordinary trailing spaces from rendered typing reach the serializer and appear as `&#x20;` in copied Markdown, the unresolved human-reported defect explicitly reserved for this reconciliation. ## Three riskiest things

1. Clipboard and browser DOM reconstruction bypass the mdast→PM→mdast corpus path; green conversion coverage leaves a routine text operation able to discard document structure.
2. Cursor correctness crosses raw source, canonical source and rendered coordinates. Bounds-only assertions and corpus omissions hide cases where the next keystroke edits the wrong location.
3. Human acceptance and performance remain evidence obligations: the reader failure has no established minimal cause, the writing volume is undocumented, and both local latency measurements require the promised reconciliation follow-up.

## Class-level lessons (for docs/lessons.md)

- LESSON: A model conversion round-trip does not cover the editor's native clipboard/DOM path → test copying supported structures back into the same editor, including opaque atoms.
- LESSON: Raw source coordinates and canonical serializer coordinates agree only accidentally → explicitly translate between them and assert the independently expected edit location.
- LESSON: Mutually inverse approximations can pass round-trip and bounds checks while pointing to the wrong character → include escapes, continuation prefixes and empty structures with semantic cursor assertions.
- LESSON: A corpus can omit structures another feature creates immediately → feed input-rule output into position mapping and view toggling, including empty table bodies.
- LESSON: Coverage percentages and synthetic CSS probes do not establish user-visible integration → assert real token DOM and measure the actual typing route at the required document size.
- LESSON: An accepted observation record may still describe unresolved failures → preserve the payload and body, separate observed symptoms from causal hypotheses, and assign the promised repair at reconciliation.
