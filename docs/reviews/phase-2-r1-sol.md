## Findings (≤ 20, most severe first)

Severity, rated by the consequence for the gate's criterion and never by the size of the fix (DECISIONS #review-1-r1): **blocker** — a gate criterion is not met, or wrong output reaches the user silently (example: Copy Markdown puts stale text on the clipboard and reports "Copied"); **should-fix** — a defect or a missing guard the phase should not close with, while the criterion still holds or the path is not the gate's own instrument (example: a redo chord bound under two names with no test that reads the binding table, so deleting one name stays green); **nit** — wording, citations, style, or an assertion with no behaviour behind it (example: `expect(checked).toBe(Object.keys(index).length)` where both sides are the same list). Mark a should-fix **Required** when the reconciliation should fail without it.

1. **blocker** — `apps/desktop/src/workspace/DocumentPane.tsx:144`, `apps/desktop/src/workspace/sidecar-sync.ts:50` — U5 still silently loses externally synced metadata on the second autosave because the first reconciliation advances `sidecarKnownRaw` without updating the authoritative in-memory sidecar. Native reproduction: open a.md with no sidecar; externally create a valid sidecar containing `title: "Synced title"`, `topicQuestion: "Synced question"`; type X and wait for save; type Y and wait again. First save preserves both fields; second save writes both as null (`/report/native-probes.log:6–7`). On that second call disk equals knownRaw, so the helper chooses the stale store copy at line 52. The new e2e asserts only the first save (`e2e/shell/test/autosave.spec.ts:101`). Fix: adopt the reconciled sidecar into the authoritative state used by subsequent saves, together with its raw baseline, preserving Markdown edits made during I/O; add consecutive-save and Markdown-reload-then-save regressions asserting that all externally supplied metadata survives, for initially absent and existing sidecars.

2. **blocker** — `apps/desktop/src-tauri/src/lib.rs:71`, `apps/desktop/src/App.tsx:105` — U2's ordinary macOS Quit path still terminates without flushing pending edits or respecting a save conflict. The app retains Tauri's default menu; installed Tauri 2.11.5 `src/app.rs:2245` installs it and `src/menu/menu.rs:194` supplies predefined Quit. Muda 0.19.3 `macos/mod.rs:994` maps that item to `terminate:`, while tao 0.35.3 `app_delegate.rs:131`/`app_state.rs:272` goes directly to LoopDestroyed. The only app barrier is onCloseRequested; no custom Quit route was added. Task 2.17's own final transcript explicitly states that Quit still loses an in-debounce keystroke and leaves it for the principal (`/logs/tasks/2.17/1.log:255`, extracted with source excerpts in `/report/quit-evidence.log`). This is source-confirmed, not locally reproduced on macOS; accepted close.spec.ts injects a different event. The approved U2 fix included close **and quit**, and no subsequent acceptance of this loss appears in the dispositions. Fix: replace the native predefined Quit action with a cancellable application-owned action that reaches the checked save/close barrier, awaits successful saves before termination, and retains the window on conflict/failure. Verify the actual menu/Cmd+Q route on macOS with pending text and each not-saved outcome; an ExitRequested handler alone does not intercept this installed route.

## Three riskiest things

1. Reconciliation updates disk provenance independently of the editor state. A one-save test certifies the temporary output while the next normal action destroys it; finding 1 is reproduced in the native application.
2. Native shutdown has multiple entry points. The injected close event and four pure decision tests do not cover the default macOS Quit action; task 2.17 already identified that remaining loss.
3. Rename spans the document, sidecar, assets and live editor. Current splice/rollback and re-read guards pass, but their proof remains bounded to the enumerated failures and supported destination spellings; the repair must not be treated as a general filesystem transaction or concurrency guarantee.

## Class-level lessons (for docs/lessons.md)

- LESSON: Advancing a disk baseline without adopting the reconciled value makes stale memory look authoritative on the next write → update provenance and authoritative state together, and test at least two saves after an external change.
- LESSON: A successful injected lifecycle event does not prove that every native termination action raises it → trace each user-facing shutdown entry point to the checked save barrier and test the actual platform action.
- LESSON: Discovering that a prescribed hook cannot observe the failing action leaves the original defect open → distinguish a completed wiring test from resolution of the user-visible loss before marking the repair complete.
