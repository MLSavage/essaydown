## Findings (≤ 20, most severe first)

Severity, rated by the consequence for the gate's criterion and never by the size of the fix (DECISIONS #review-1-r1): **blocker** — a gate criterion is not met, or wrong output reaches the user silently (example: Copy Markdown puts stale text on the clipboard and reports "Copied"); **should-fix** — a defect or a missing guard the phase should not close with, while the criterion still holds or the path is not the gate's own instrument (example: a redo chord bound under two names with no test that reads the binding table, so deleting one name stays green); **nit** — wording, citations, style, or an assertion with no behaviour behind it (example: `expect(checked).toBe(Object.keys(index).length)` where both sides are the same list). Mark a should-fix **Required** when the reconciliation should fail without it.

1. **should-fix — Required** — **packages/editor/src/toggle.ts:508** — An interior boundary whose typed marks match neither neighbouring run is assigned to the following run, so toggling changes the next character's formatting. Load `q [ab](u)*cd* r`, click inside the link and ArrowRight to its end; the editor readout has `before: "q ab", marks: [], stored: null`. Typing X directly copies `q [ab](u)X*cd* r`; toggle then X copies `q [ab](u)*Xcd* r`. The link is non-inclusive, and the following emphasis is not inherited, so neither node is the correct inside position. `innermostAt` only distinguishes “equals before” from “everything else.” A related carried-subset case, `q *x [ab](u)* r` at the link's end, copies `q *x [ab](u)X* r` directly but `q \*x [ab](u)\*X r` after toggle. Thus the newly recorded 1.64 limitation is not confined to block-final positions. Evidence: [boundary-browser.mjs](boundary-browser.mjs), [boundary-browser.log](boundary-browser.log), [sweep.json](sweep.json). **Fix:** resolve an interior boundary per carried mark, allowing a source point between the two runs or inside a shared enclosing mark; do not assume inequality with the preceding mark set implies equality with the following one. Add native two-route and corpus byte-equivalence guards for non-inclusive links followed by each mark, shared enclosing marks, both edges and astral text. The literal copied-Markdown fixed point still holds, so this is rated consistently with N1/N2 as Required cursor correctness.

2. **should-fix — Required** — **packages/editor/src/toggle.ts:675** — The dropped-whitespace shortcut returns outside every enclosing mark even when the live caret still carries one. Load `*x ` + backtick + `bc` + backtick + `*`, ArrowUp to the one-line paragraph start, Delete x, then ArrowRight past the surviving space. The editor readout is `before: " ", marks: ["emphasis"], stored: null`. Direct X copies `*X` + backtick + `bc` + backtick + `*`; toggle then X copies `X\*` + backtick + `bc` + backtick + `\*`. `beyondDroppedWhitespace` sees that `[emphasis]` differs from `[emphasis, inline_code]`; `betweenNodes` returns the outer emphasis's start and the early return bypasses markEdgePoint. This is a retained boundary after dropped whitespace, not a position deliberately excluded by the settling rule. Evidence: [marked-gap-browser.mjs](marked-gap-browser.mjs), [marked-gap-browser.log](marked-gap-browser.log); the sweep also reaches strong/delete and nested-mark members. **Fix:** carry the typed-mark set through the dropped-gap resolution and place the caret inside surviving enclosing marks but outside the uncarried leaf. Add destructive two-view guards where deleting leading content leaves marked whitespace before code or another nested mark, across the textblock containers; assert bytes beside the inverse. Do not restore stripped whitespace or alter the user's live buffer.

3. **should-fix — Required** — **packages/editor/src/toggle.ts:692** — The leaf-start counterpart of the code-span end rule is missing, and ordinary deletion reaches it without a mark-toggle command. Load `a` + backtick + `bc` + backtick, ArrowUp, Delete a. The caret is now at the block start with `marks: ["inline_code"], stored: []`. Direct X copies `X` + backtick + `bc` + backtick; toggle then X copies backtick + `Xbc` + backtick. The unconditional spelling-table start is inside the fence, while the live transaction inserts plain text. ## Three riskiest things

1. Cursor ownership uses complete mark-set equality in several independent branches. A retained subset, neither-neighbour set, or normalization gap bypasses the block-edge rule; current isolated-mark matrices do not establish the cross-product invariant.
2. Green inverse tests can validate a shared coordinate convention while missing different inserted bytes. The new destructive leg improves this but still has explicit exclusions, and an arbitrary stored-mark state can produce an impossible source-insertion oracle. Native reachability must accompany minimized failures.
3. The human observation predates the repair chain, while deferred source commits still take 42.2 ms p95 locally and up to 96.0 ms in accepted CI. The recorded human-recheck question and Phase 2 deferral triggers remain material; this review neither grants human approval nor advances those deadlines.

- LESSON: a leaf-start defect was recorded as an input-rule edge case although Delete also produces cleared stored marks → vary the native action that reaches a state, and revisit a task's scope exclusion at its named review trigger.
