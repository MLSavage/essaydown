## Findings (≤ 20, most severe first)

1. **blocker** — packages/core/src/format.ts:1293–1295 (`installAutolinkFallback`'s `link` wrapper) with :1235 (`autolinkCarriesUrl`). C14 reproduces: a URL holding `|` typed into a table cell splits the row on the second save, so wrong bytes reach the file silently. The probe types ` https://a.b/x|y` after `c` in `| a | b |\n| - | - |\n| c | d |\n` through the real input-rule route (`Typing` over `editorPlugins()`), and the editor's tree is `table_cell("c https://a.b/x|y")`.
   - Save 1 writes `| c https\://a.b/x\|y | d |`, which is 2 cells. GFM's literal transform still reads `https\://a.b/x|y` as an autolink literal, because the `\:` escape does not stop it: parse gives `link{url:"https://a.b/x|y", data.autolinkLiteral}`.
   - Save 2 (reopen, then any edit, by the editor route `format(pmToMdast(mdastToPM(parse(s1))))` or the core route `format(parse(s1))` alike) writes `| c <https://a.b/x|y> | d |`. The link is not written bare, so the built-in `<…>` branch runs. That branch empties `state.stack` (the comment at :1245–1246), so the gfm-table `|` unsafe pattern never fires. `autolinkCarriesUrl` compares only the url bytes and accepts the value. A raw `|` in a cell is a column separator, so this file already parses as body row `[2→3]` cells in every GFM reader (Typora, GitHub).
   - Save 3 widens the table: `| a | b  |   |\n| ----------------- | -- | - |\n| c \<https://a.b/x | y> | d |`. The header now has 3 columns, the URL is cut in two and a backslash appears, so invariant B is broken through the writing surface.
   - Fix: in the wrapper, when `state.stack` (before the built-in empties it) includes `tableCell` and the `<…>` value contains `|`, treat the form as not carrying the url and take `asResourceLink`. The resource form's label and destination go through `safe()`, so the cell's `\|` escape applies. Also make the bare-literal path agree inside a cell, so save 1 is already a fixed point.
   - Guards: one typed member (the probe above, saved three times, asserting a fixed point and an unchanged column count on every save) and one hand-built-tree member (`tableCell > link{autolinkLiteral, url with "|"}`) in url-typing.test.ts / url-bytes.test.ts, with an astral member beside the ASCII one. Also add the cell class to the URL corpus leg (CLAUDE.md M1: one guard member per literal node class, here a link inside a cell).

## Three riskiest things

1. **Literal-URL bytes inside tables.** Finding 1 means 3.14's "the writer's bytes" path and the r6 L2 `<…>` fallback were each checked only in phrasing outside a cell. The table cell is the one container whose unsafe set (`|`) the `<…>` branch hides. Every other container with its own unsafe characters inside link text is unprobed by this review (scope), and is the next place to look.
2. **The source view during an awaited flush (from reading, not run; outside the 3.24 diff).** `DocumentPane.tsx`'s `flush` settles the source burst once, before `sync.flush()`. `saveOnce`/`drain` (document-sync.ts:239–272) loop on `dirty` but never settle again after the awaited read/write, so a CodeMirror burst typed after Cmd+W, while the IPC is in flight, is still uncommitted when `drain` returns `saved` and the window closes. It is the W1 class on the source surface only; the rendered view commits per keystroke. I did not report it: the keystrokes follow the user's own discard command, the window is one IPC round-trip, and the scope bars the probe that would confirm it. The same once-only settle precedes the awaited move in `renamed` (document-sync.ts:402–421).
3. **§6.2 resolution with shifted duplicate occurrences (from reading, not run; predates 3.22).** `resolveAnchor` step 2 matches hash plus a document-wide `occurrence` (sidecar.ts:221, :391). If a paragraph whose text duplicates an anchored sentence is typed above both twins, the occurrence shifts and the variant resolves onto the other twin. Cards, saves and, since 3.22, moves then agree on the wrong item. 3.22's guard 5 (sidecar.test.ts:738) prepends a non-duplicate, so it cannot see this. It is a property of the specified algorithm, not a 3.22 defect, and is named here so the Phase 4 boundary can decide.

## Class-level lessons (for docs/lessons.md)

- LESSON: a serializer branch that hides the construct stack (mdast-util-to-markdown's `<…>` autolink sets `state.stack = []`) also hides every container's unsafe characters, and the URL guards were enumerated only in phrasing outside a table → every guard family for a stack-hiding branch carries one member per container with its own unsafe set (a table cell's `|`), saved at least three times through the writing surface, asserting the column count as well as the fixed point.
- LESSON: a backslash escape does not stop the GFM autolink-literal transform (it runs on decoded text), so "escape it so the parser leaves it alone" is false for literals, and the second save sees a link the first save thought it had written as text → a URL-shaped text guard asserts the node types of `parse(save₁)` against the editor's tree (CLAUDE.md M2), not only the bytes of save₁.
