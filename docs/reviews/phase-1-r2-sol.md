## Findings (≤ 20, most severe first)

Severity, rated by the consequence for the gate's criterion and never by the size of the fix (DECISIONS #review-1-r1): **blocker** — a gate criterion is not met, or wrong output reaches the user silently (example: Copy Markdown puts stale text on the clipboard and reports "Copied"); **should-fix** — a defect or a missing guard the phase should not close with, while the criterion still holds or the path is not the gate's own instrument (example: a redo chord bound under two names with no test that reads the binding table, so deleting one name stays green); **nit** — wording, citations, style, or an assertion with no behaviour behind it (example: `expect(checked).toBe(Object.keys(index).length)` where both sides are the same list). Mark a should-fix **Required** when the reconciliation should fail without it.

1. **blocker** — packages/editor/src/toggle.ts:628 — A flush inside a continuous source typing burst still splits undo history when the continuation lasts longer than one coalescing window. Reproduction: open a blank /dev/editor, toggle to source, type `a`, click Copy Markdown, return to the source caret, type `bcdef` at 300 ms per character, then immediately press Ctrl+Z. Observed `a` remains; Ctrl+Shift+Z restores `abcdef`. Recorded beforeinput times were 242.4, 307.6, 611.6, 923.7, 1237.3 and 1542.7 ms: every adjacent gap is below 314 ms, but the two committed snapshots' final-keystroke times differ by 1300.3 ms. Without Copy, the continuous burst undoes to empty. `pendingAt` retains only the latest event, so core/undo.ts's comparison against the previous committed event cannot see the intervening keystrokes. The task 1.24 case-3 test stops its continuation at 200 ms and misses this. Fix: carry both the pending segment's first and last event times; decide continuity against its first event and the previous entry's last event, while retaining the last event for the next comparison. Preserve explicit group closure on toggle/history actions. Add fake-clock and browser regressions with total continuation duration above one window but every adjacent gap below it, plus the genuine-gap absence case; test both timed and explicitly flushed endings. Evidence: /report/probe.mjs, probe.log, control.mjs, control.log.

2. **nit** — docs/V1.1-BACKLOG.md:44 — The stated reason for deferring the emphasis-edge case, that it is unreachable without a mark-toggle command, is false. Loading `a *b* c`, placing the rendered caret immediately after `b`, and typing a space produces exactly `a *b&#x20;*&#x20;c`; /report/probe.mjs reproduces it using ordinary keyboard events. This finding corrects the reachability claim; it does not assert that those valid character references themselves prove semantic loss. Fix: append a correction to the append-only backlog with this current-route reproduction, and have reconciliation reconsider the trigger using actual reachability rather than the future introduction of mark toggles.

## Three riskiest things

1. Deferred source commits now affect both the content read by commands and the grouping of history. Single-keystroke continuations cannot establish equivalence to the original sliding coalescing window; finding 1 survives all existing tests.
2. Whitespace normalization is tested heavily at block and line boundaries, but marked text can reach boundary shapes through ordinary caret edits. The backlog currently misclassifies one such shape as unreachable.
3. The application wiring has browser-test evidence but no measured coverage, and deferred source parsing has no latency metric. Phase 2 save/autosave readers will add consumers precisely at that boundary; the existing backlog hard stops remain relevant.

## Class-level lessons (for docs/lessons.md)

- LESSON: retaining only the final event timestamp of a deferred batch loses the adjacency information used by sliding-window undo → retain the batch's first and last event times separately, and test chains longer than the window with every neighboring gap shorter than it.
- LESSON: absence of a formatting command does not make a marked-node shape unreachable → try cursor insertion and deletion inside existing formatting before deferring a conversion defect on reachability grounds.
