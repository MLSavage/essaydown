## Three riskiest things

1. Sidecar state now has three copies (the store's, `sidecarKnownRaw`, the disk) and only two of them move on a write; any later sidecar feature (Phase 3 titles, outline anchors) inherits finding 1's stale baseline unless the baseline is unified.
2. Every macOS exit path that is not a window close (menu Quit, Dock Quit, logout, `terminate:` from anywhere) bypasses the barrier, and the e2e cannot drive any of them; the only proof of the quit path will be a manual check.
3. `rewriteAssetUrls`'s per-candidate full re-parse (assets.ts:110-111) is quadratic in matching destinations and is computed on the UI thread inside `commitRename`; a destination it cannot prove (an encoded prefix) is silently left pointing at the moved directory.

## Class-level lessons (for docs/lessons.md)

- LESSON: a "re-read the disk before writing, the disk wins when it changed" fix moved the raw baseline but not the parsed state the next write is built from, and its e2e asserted after one write only → a fix that adopts external state asserts the adopted value after the second write (and after a reload), never only the first.
- LESSON: a task that reads "the installed runtime raises no event for this path" and then changes nothing closed half of a blocker with no disposition → when a prescribed hook is found not to exist, the path is either replaced by one that raises the event (a custom menu item) or recorded as a backlog line with a trigger before the task reports DONE.
