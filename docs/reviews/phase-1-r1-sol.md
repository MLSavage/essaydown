## Findings (≤ 20, most severe first)

1. **should-fix** — apps/desktop/src/dev/DevEditor.tsx:208 — Copy Markdown reads the old store snapshot during the source view's deferred commit window and reports success while omitting visible edits. Required. `/report/probes.cjs` loads `base\n`, toggles source, appends `fresh`, and immediately clicks Copy: clipboard is `base\n`; after the timer the document is `base\nfresh\n`. Fix: flush the current source binding before reading the root in copyMarkdown; add a browser case that copies inside the burst window and asserts the clipboard includes the final edit without requiring a pause or toggle.

2. **should-fix** — packages/editor/src/store.ts:258 — Source Undo/Redo operates on committed history without settling the pending source burst, so immediate Undo either does nothing or removes the previous burst and permanently discards the new one. Required. `/report/cursor-undo.log`: on a fresh route type `first` in source and immediately Undo; the surface remains `first` and the timer later commits it. Separately, type `first`, wait 1.2 seconds, type ` second`, immediately Undo then Redo: output is only `first\n`, never `first second\n`. bindCodeMirror's pull drops pending text at toggle.ts:609. Fix: route source history commands through a boundary that commits the pending burst before moving history, preserving burst grouping and redo semantics; test fresh-history, previous-burst, and pending-edit-after-undo cases with an injected clock plus real browser chords inside the window.

3. **should-fix** — packages/editor/src/schema.ts:193 — Ordinary rendered typing replaces existing soft newlines with spaces in the edited paragraph, altering unrelated source bytes. Required. Independent rendered-only probe loads `alpha\nbeta\n`, puts the caret at the end, types X, and receives `alpha betaX\n` instead of `alpha\nbetaX\n`. e2e/web/editor-cursor.spec.ts:84 explicitly expects the same defect in a blockquote; no principal deferral exists. The clipboard parseDOM `preserveWhitespace: "full"` setting does not cover incremental DOM edits: installed prosemirror-view/src/domchange.ts:45 derives that setting from the parent node type's `whitespace` property. Fix: preserve soft newlines on the actual DOM-change parse path (for example, appropriate node whitespace settings), and add typing cases for wrapped paragraphs and nested blockquotes; replace the cursor test's loss-accepting expectation with the preserved bytes. Keep code and hard-break behavior covered.

4. **should-fix** — packages/core/test/positions-corpus.test.ts:79 — The promoted rule requires an editor-output-seeded corpus leg for the position-map family, but its corpus tests still use parser-seeded roots exclusively. Required. The journal cites editor-fixed-point.test.ts, which tests formatting but does not exercise formatWithMap or cursor correspondence. Fix: for every indexed fixture, apply a typing-shaped ProseMirror transaction, convert its resulting document to mdast, feed that root into formatWithMap and the relevant position correspondence checks, and assert the output's parse/format fixed point; name the editor-output leg in the test title and record the actual map test in the journal. This can live in editor tests to keep core free of an editor dependency.

## Three riskiest things

1. Deferred source commits create two document versions; Copy and history already consume the stale one. Future save/autosave integration must use an explicit pending-edit boundary.
2. Clipboard reconstruction, DOM-observer typing and headless transactions take different parse paths. Corpus clipboard success did not prevent a rendered keystroke from changing a soft newline elsewhere in its paragraph.
3. Rendered typing remains proportional to document size. Isolated local latency is below budget, while all accepted CI runners exceed it; the size-ratio test tolerates both and is not an absolute performance guarantee.

## Class-level lessons (for docs/lessons.md)

- LESSON: Deferring a store commit changes every reader and history command's precondition → enumerate all document consumers and settle pending edits explicitly before Copy, Undo, Redo and persistence; test actions during the pending window.
- LESSON: A clipboard parse rule does not control incremental DOM-observer parsing → test real typing into pre-existing wrapped text and preserve whitespace at the framework path that reparses it.
- LESSON: Promoting a rule that names multiple round-trip families is not discharged by one nearby conversion test → map each named family to a test that actually calls that family's operation on editor-generated output.
- LESSON: A green relative-latency assertion can coexist with an exceeded absolute budget → record the protocol, contention, sample count and isolated rerun separately from CI pass/fail.
