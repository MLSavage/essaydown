## Findings (≤ 20, most severe first)

Severity, rated by the consequence for the gate's criterion and never by the size of the fix (DECISIONS #review-1-r1): **blocker** — a gate criterion is not met, or wrong output reaches the user silently (example: Copy Markdown puts stale text on the clipboard and reports "Copied"); **should-fix** — a defect or a missing guard the phase should not close with, while the criterion still holds or the path is not the gate's own instrument (example: a redo chord bound under two names with no test that reads the binding table, so deleting one name stays green); **nit** — wording, citations, style, or an assertion with no behaviour behind it (example: `expect(checked).toBe(Object.keys(index).length)` where both sides are the same list). Mark a should-fix **Required** when the reconciliation should fail without it.

1. **blocker** — `packages/core/src/format.ts:786` (`handleRoot`'s handler set; the class is the built-in `emphasis`/`strong` handlers it leaves in place) — when two flanking runs become adjacent and the first one's last character is punctuation, the serializer writes their delimiters as one run and the bytes parse to a different tree: `emphasis("(b)") + strong("z")` → `*(b)***z**`, which parses as `text("*(b)*") + strong("z")`, and `strong("(b)") + emphasis("z")` → `**(b)***z*`, likewise; Copy Markdown puts those bytes on the clipboard and reports `Copied Markdown`. Two one-keystroke routes, both driven here: **Backspace** at the start of the second of two paragraphs (`baseKeymap`'s `joinBackward`, `packages/editor/src/input.ts:236`) — confirmed in Chromium on `/dev/editor` with the 1.62 selection readout as the precondition — and **Delete of the single space** between two runs in one paragraph (`*(b)* **z**` → `*(b)***z**`), which is `deleteBesideEveryMarkedRun`'s own shape on a pair no fixture holds. This is `[review-1-r6 L11]`'s class with a false premise: the line defers it as "unreachable from the editor (adjacent same-mark text merges into one run)", and the reachable members are the **different**-mark pairs, which nothing merges. Exactly 2 of the 75 editor-producible ordered pairs break (sweep D); the letter and astral endings are clean, as are all 25 `delete`-first and `delete`-second pairs. Fix: give `emphasis` and `strong` app handlers in the shape `handleDelete` (`format.ts:131`) already has — when the node's preceding sibling's bytes end in the same delimiter character, write this run with the alternative delimiter (`_` / `__`), which parses back to the editor's own tree (verified: `parse("*(b)*__z__")` is `emphasis + strong`) and is a fixed point once the rule is a function of the tree; and add the corpus leg the class needs (a join leg and a delete-the-separator leg, enumerated over ordered pairs of mark kinds × both neighbour classes CommonMark §6.2 names, with an astral member), because every committed leg edits one position inside one block and none of them makes two nodes adjacent.
2. **should-fix** — `packages/editor/test/position-map-inverse.test.ts:583` and `packages/editor/test/toggle.test.ts:2009` — both corpus byte legs compare the two views on the block alone and bridge to the document with `shift = { line: source.line, ch: source.ch - inBlock.ch }`, asserting only that the shift is *the same* across the routes and positions that share a block-local line; nothing compares the whole document's own column against the document's bytes, so a per-line constant error in the document map (a container prefix, an ordered marker that widens at item 10) satisfies both legs while the test title claims "the block's columns are the document's". The claim is currently true — I ran the document-level oracle myself (sweeps A and B, 5,309 comparisons, 0 disagreements outside the recorded classes) — so this is guard power, not a live defect. Fix: assert the bridge against the document's bytes, e.g. `document.split("\n")[source.line - 1].slice(shift.ch)` starts the block-alone line's own text, or run `typedInSource(documentText, source)` once per block line beside the block-local comparison.
3. **should-fix** — `e2e/web/editor-soft-line-breaks.spec.ts:181` — the caret precondition after the computed-point click is a race under load: in the first of three full-suite runs in this container the poll timed out with the caret still at the seed position (`offset 16`, expected `5`), i.e. the click was lost or landed outside the text after the layout it was computed from moved; the same spec alone with `--workers=1` is 3/3 green and CI was green on all three runners. This is the fifth caret-precondition race of the phase (#029, #035, #036, #037 are the four gates it failed). Fix: re-read the geometry and re-click while the readout still shows the seed offset (bounded retry), or place the caret through a route that cannot be lost — assert the readout, then counted `ArrowLeft` from the asserted position — rather than a single `mouse.click` whose effect is only polled for.
4. **should-fix** — `packages/core/src/positions.ts:1060` — 1.65's instrument enumerates two give-up reasons but only `unlocatable-child` is ever carried through `buildMap` into `unresolved`; the `overlapping-edit` arm of this ternary is the file's uncovered branch, because the only tests of that reason call `applyEdits` directly (`format-widening-giveup.test.ts:145,154`). 5. **nit** — `packages/editor/src/toggle.ts:414` and `:420` — `leafOffset`/`leafPosition`'s `entry.inline === undefined` arms are never executed by the suite (both are uncovered statements) and are defended by a doc-comment sentence ("Where an entry has no map … the two are the plain arithmetic they were"), which is the same shape as the give-up N3 was raised for. ## Class-level lessons (for docs/lessons.md)

- LESSON: a backlog line that defers a defect as "unreachable from the editor" states a claim about the command set, and the reason it gives can be true of one member and false of its siblings (adjacent *same*-mark runs merge; adjacent *different*-mark runs do not) → a deferral of that shape names the commands it was read against, and the next review re-drives the route through the keymap the app actually installs instead of re-reading the sentence.
- LESSON: every round-trip leg seeded from the writing surface edited one position inside one block, so the trees that need two nodes to become adjacent — a join, a deletion of the whole separator, a paste — were outside all of them → a round-trip family gets one leg whose transaction removes a *node* between two others and one that joins two blocks, enumerated over ordered pairs of the schema's inline kinds × both neighbour classes CommonMark §6.2 names, with an astral member.
- LESSON: when an oracle is moved from the whole document to a local unit for cost, the bridge back must read the document's own bytes; a shift computed from both sides and asserted only against itself agrees whenever the two sides are wrong together, which is the defect N2 was raised for, one level up.
