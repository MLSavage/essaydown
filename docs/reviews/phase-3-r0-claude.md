## Findings (≤ 20, most severe first)

1. **blocker** — packages/editor/src/input.ts:225 — Shift+Enter right after an inline-code run inserts a `hard_break` that inherits the `inline_code` mark (`replaceSelectionWith` default `inheritMarks: true`). `pmToMdast` then folds it into the code run's string and drops it. The rendered view shows a line break that the saved file does not hold, and in the spaced case the following space is lost too. Probe at 552f186: `` `alpha`beta `` + Shift-Enter after `alpha` saves `` `alpha`beta\n `` (tree `inline_code(hard_break)`), and `` `alpha` beta `` saves `` `alpha`beta\n `` (break and space both gone). `x `` `alpha` `` at a block end loses the break too. 3.16 shipped the feature and filed this as `[3.16, found outside scope]` with hard stop 3.verify; 3.verify recorded "none". This is wrong output reaching the user silently, from the phase's own new feature. Fix: `replaceSelectionWith(schema.nodes.hard_break.create(), false)`, or strip `inline_code` (and `link`) from the inherited marks in `insertHardBreak`. Add a guard enumerating every mark kind × both edges, asserting the break's presence in `format(pmToMdast(·))` and the parse∘format fixed point. 3.16's acceptance names that fixed point, and input.test.ts:290–338 never asserts it.

2. **should-fix (Required)** — packages/core/src/format.ts:1001 (`literalSpans`), :1075, :1223 — 3.14's text says a bare URL "is never rewritten as `<…>` and never escaped", and that the writer's bytes are the reference. A URL ending in a character GFM trims (`_`, `*`, `~`) breaks both rules, because the spans come from the mdast transform, not the tokenizer's trailing-punctuation rule. Typed `Hello https://a.b/x_y_` saves `Hello https\://a.b/x\_y\_`, and the next save gives `Hello <https://a.b/x_y_>`, so the editor's output is not a fixed point (invariant A). Typed `see https://a.b/x~ ok` behaves the same way. Loaded `https://a.b/x_\n` saves `<https://a.b/x>\_\n`, so an unedited Typora-written file has its bytes rewritten on the first save. Fix: take literal spans from micromark's own reading (trailing-punctuation trim included), try the following character raw before escaping, and add one typed and one loaded guard per trimmed character to url-bytes.test.ts / url-typing.test.ts.

3. **should-fix (Required)** — packages/editor/src/toggle.ts:633–634; packages/editor/test/typed-marks.test.ts:119, :136 — 3.12's "stuck in italics" class survives at a block end. `typedMarks` is read at the settled position, not the live caret, which breaks rule N2. ## Three riskiest things

1. The mdast ↔ ProseMirror conversion silently drops content at a mark edge: a `hard_break` and a `link` folded into an `inline_code` run (findings 1 and 6). The family has been found one member per phase because nothing asserts, for an arbitrary editor transaction, that every node of the live doc is present in `pmToMdast`'s output. Each new editing command (Shift+Enter, and in Phase 4–5 whatever comes next) reaches a new member.
2. Mode panels are a second reader of the document that derives positions from a rebuilt tree, not the live one (finding 4), and from pre-settle snapshots (finding 5). Both put the wrong paragraph or section under a Rewrite, Reorder or Outline action. Neither is measured: apps/desktop/src is outside coverage (finding 12), and the e2e specs never edit before acting.
3. macOS, a required runner, is green only on the embedded provider's synthetic input (gate table caveat). Phase 3's 3.verifyh failure was exactly a route defect that only that leg showed. Any behaviour that depends on native key, IME or drag handling on macOS is unproved until Michael's manual pass or a native driver route exists.

## Class-level lessons (for docs/lessons.md)

- LESSON: a "found outside scope" line with hard stop `N.verify` is read by the verify task and recorded as "none" when no task took it, so silent-loss defects (a Shift+Enter break, a link dropped by a keystroke) reach the review set unfixed → a backlog line that describes data loss in a feature the phase ships is a fix task in the same phase, never a hard stop the verifier can only report.
- LESSON: a panel that maps the store's cursor into a doc rebuilt from the normalised tree agrees with the live doc only when no normalisation applied (no empty paragraph, no dropped whitespace) → any consumer of an editor position resolves it in the live view's doc, and its corpus leg is seeded from a destructive transaction (CLAUDE.md N2 applies to every reader, not only the cursor map).
- LESSON: a reproduction test that re-implements the caller it is meant to guard stays green when the caller regresses → the reproduction imports the production sequence (extract it from the component if needed), and its mutation record reverts the product file, not the replica.
- LESSON: an enumeration of "URL-shaped text" built from the mdast transform's spans misses the tokenizer's trailing-punctuation trim → derive literal boundaries from the parser's own tokenizer (CLAUDE.md J2), and enumerate each trimmed character typed and loaded.
