## Class-level lessons (for docs/lessons.md)

- LESSON: a wrapper that post-processes the two mixed raw+reference forms of a split surrogate pair does not see the join of *two* unit-width encodings of the same pair (`&#xD83D;&#xDE00;`) — the "both sides" guard with two characters is a different tree from one character between two runs → an encoding-width fix enumerates (one mark, both sides) *and* (two marks, one neighbour), and the regex / retry table names every form `container-phrasing.js`'s two rewrites can concatenate, not only each rewrite alone.
- LESSON: a read-only review that walks `handleDelete` against `encode-info.js` and never opens `container-phrasing.js` misses the neighbour encoding, which is a parent rewrite after the handler returned, one UTF-16 unit wide for every flanking mark — that is the read that would have reached K1 at `3dd9c4b` without a non-BMP fixture (`😀.charCodeAt(0)` is `0xD83D`) → the first read of a flanking review is the assembler's two rewrites, then the handler, then the pin's neighbouring branch.
- LESSON: an enumeration of mark × side × inner × neighbour that builds one run per case cannot fail on a neighbour two runs share, and a corpus fixture of three one-mark paragraphs cannot either → a neighbour-class enumeration includes the cell where the same outside character is the closing neighbour of one run and the opening neighbour of the next.
