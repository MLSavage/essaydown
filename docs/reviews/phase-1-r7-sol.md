## Findings (≤ 20, most severe first)

Severity, rated by the consequence for the gate's criterion and never by the size of the fix (DECISIONS #review-1-r1): **blocker** — a gate criterion is not met, or wrong output reaches the user silently (example: Copy Markdown puts stale text on the clipboard and reports "Copied"); **should-fix** — a defect or a missing guard the phase should not close with, while the criterion still holds or the path is not the gate's own instrument (example: a redo chord bound under two names with no test that reads the binding table, so deleting one name stays green); **nit** — wording, citations, style, or an assertion with no behaviour behind it (example: `expect(checked).toBe(Object.keys(index).length)` where both sides are the same list). Mark a should-fix **Required** when the reconciliation should fail without it.

1. **blocker** — **packages/core/src/format.ts:288**; **packages/core/test/positions.test.ts:323** — Copy silently replaces a hard break immediately before inline HTML with a literal backslash and space. Load the bytes `alpha\\\n<i>beta</i>\n` (backslash, then LF after `alpha`) through the dev bar: the parsed tree and rendered view contain a hard break. Copy reports success but writes `alpha\\ <i>beta</i>\n`; reparsing contains **zero break nodes**, and the backslash has become visible text. `/report/hardbreak-browser.mjs` and `.log` reproduce the actual clipboard path and the 1 → 0 count. The inherited `container-phrasing.js:60–80` rewrites the break handler's final LF to a space; the app's wrapper passes it through, and the position-map test explicitly pins the corrupted bytes. This is not the accepted soft-break normalization: a hard break changes semantics, and a new literal character is introduced. **Fix:** make the app-owned phrasing serialization preserve `\\\n` before inline HTML rather than applying that EOL-to-space rewrite to a `break` emission; retain opaque HTML bytes and update map instrumentation for the preserved emission. Add this source to the fixture corpus and assert semantic break preservation as well as fixed-point stability, including a rendered deletion that puts a break next to the raw inline node and a Copy Markdown browser test. Replace the test's corrupted-output expectation. A fixed-point-only test is insufficient: this corrupted result is already stable.

2. **should-fix — Required** — **packages/core/src/positions.ts:710** — `inlineCodeSpelling` assumes an inline-code value is written one UTF-16 unit per unit, omitting the installed GFM table handler's pipe escaping. `mdast-util-gfm-table/lib/index.js:291–298` wraps the base code handler and inserts a backslash before every pipe inside a cell. For value `a|b`, the emitted inner value `a\|b` fails the length check, so no spelling table is installed even though `map.unresolved` is empty. Browser reproduction: load `| h | ` followed by the code span `` `a\|b` `` and ` |`, with a normal delimiter row; click immediately after `a` (asserted text `a|b`, offset 1), toggle source and back, type `X`, then Copy. The code becomes **`Xa|b`**, not **`aX|b`**. `/report/pipe-browser.mjs` and `.log` record the result; the larger probe finds 16 inverse failures across parse/deletion variants. **Fix:** construct inline-code spelling offsets from the actual configured handler, accounting for each GFM `\|` escape separately from fence padding and from literal backslashes outside tables. Add a corpus fixture covering plain/astral code beside a pipe in a cell, inverse/monotonicity checks before and after deletion, and the toggle-then-type browser case. Include a non-table `\|` absence guard so a literal backslash is not incorrectly consumed.

## Three riskiest things

1. Stable serialization can already have lost semantics. The hard-break case is explicitly pinned as an unresolved-map example, while invariant A remains green. Tests must compare the original editor/tree semantics, not only repeated output.
2. Base-handler coverage does not cover configured extension handlers. Table inline-code escaping bypasses the new spelling table without adding an unresolved entry; fenced-code interiors also remain explicitly deferred to `2.verify`.
3. The 16 ms typing result is load-sensitive, and source commits take approximately 52–83 ms in these measurements. Phase 2 autosave/watchers must account for those costs and settle pending source edits before reading.

## Class-level lessons (for docs/lessons.md)

- LESSON: A serializer's lossy rewrite can produce an immediate fixed point → pair idempotence with semantic assertions against the pre-serialization tree, especially where a known rewrite is pinned by a test.
- LESSON: Reading a base handler misses behavior installed by an enabled extension → derive spelling rules from the final configured handler and test its delimiter escapes in their enabling context and outside it.
- LESSON: An empty unresolved-node list proves node placement, not character correspondence → assert inverse cursor mapping over every editable position, including values whose spelling table could not be constructed.
