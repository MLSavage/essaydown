Phase 2 adds the shell, autosave and external-change paths on top of this serializer; a rewrite the walk cannot follow will show up as bytes on Michael's disk, not as a red test.

## Class-level lessons (for docs/lessons.md)

- LESSON: a doc comment that discharges an untested branch by citing a guard in another file names that guard but never asserts the two agree → when a branch's safety argument rests on a second implementation ("X enumerates the same forms"), the guard is a test that runs both and compares, not a sentence; the uncovered line in the coverage report is where to look for the pair.
- LESSON: an allowlist that justifies a dependency by citing a PRD row certifies the package name and never the version the row states, so a major-version drift passes "zero dependencies beyond §4" at every attempt → a dependency check that cites a spec row compares what the row says (name *and* version) against what is installed, or the citation is decoration.
- LESSON: a human observation gate satisfies its criterion at the SHA it was recorded at, not at the SHA the phase closes on, and a gate whose own record reports the defect the phase then spent eight attempts fixing certifies nothing about the fix → when an observation gate's record names a defect, the disposition schedules a second observation at the fixed SHA in the same commit that files the fix task, rather than leaving it to a backlog trigger that no attempt fires.
- LESSON: a sweep that widens one axis (pairs of inline forms) and finds nothing has tested one axis; the members found at r4, r6 and r7 each lived on an axis the previous sweep held fixed → a reviewer's sweep states which axes it varied and which it held fixed, so the next attempt can pick an axis rather than re-run the same one wider.
