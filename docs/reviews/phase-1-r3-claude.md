## Findings (≤ 20, most severe first)

Severity, rated by the consequence for the gate's criterion and never by the size of the fix (DECISIONS #review-1-r1): **blocker** — a gate criterion is not met, or wrong output reaches the user silently (example: Copy Markdown puts stale text on the clipboard and reports "Copied"); **should-fix** — a defect or a missing guard the phase should not close with, while the criterion still holds or the path is not the gate's own instrument (example: a redo chord bound under two names with no test that reads the binding table, so deleting one name stays green); **nit** — wording, citations, style, or an assertion with no behaviour behind it (example: `expect(checked).toBe(Object.keys(index).length)` where both sides are the same list). Mark a should-fix **Required** when the reconciliation should fail without it.

1. **blocker** — `packages/editor/src/schema.ts:826` (`giveUpEdges`, the trailing-edge scan stops at any non-text node) and `:752–766` (the end-of-block loop only sees the *block's* last node) — a `hard_break` that is the last node of an `emphasis`/`strong`/`delete` run **with unmarked text after it** reaches `format`, which writes the break's line ending as `\&#xA;` inside the delimiters and escapes the next character (`*a\&#xA;*&#x63;`); the backslash makes the entity literal, so `parse` reads back `emphasis[text("a&#xA;")], text("c")` — the break is gone and the six characters `&#xA;` are now the essay's text, while the rendered view still shows the break and the status reads "Copied Markdown". Reproduced on `/dev/editor` (Chromium, `f90ed50`): load `*roses are red\` newline `violets are blue* — anon` (valid CommonMark; verse in italics is an ordinary essay shape), caret after `blue`, `Backspace` ×16 → pane and `writeText` `*roses are red\&#xA;*— anon\n` (the space after the closing `*` is also eaten by the line-start rule, since the break is now the run's end). Headless: `*a\` nl `b* c` + `tr.delete` of `b` → `*a\&#xA;*&#x63;\n`; `x*a\` nl `b*` + delete `a` → `&#x78;*\` nl `b*`; the setext-heading member (`*a\` nl `b* c` + `=====`, delete `b`) → `*a\&#xA;*&#x63;\n===============\n`, whose `format(parse(·))` is `# *a\&#xA;*&#x63;\n` — **not a fixed point**, so the criterion fails on its own terms there. `docs/V1.1-BACKLOG.md:52` (written by 1.30) defers exactly this tree as "Not reachable by a keystroke today (Shift-Enter is unbound), only by a rich-text paste carrying `<br>` inside `<em>`" — false: every loaded file and the source view supply the `<br>`, and the keystroke is a deletion, which is the r2 class verbatim (`[1.10.r2d]` lesson: "try insertion and deletion inside existing formatting before deferring on reachability"). The deletion leg cannot see it: `typing-legs.ts:150–163` deletes *to the block's end*, so the break is always the block's last node (dropped by 1.29's loop) and never a run's last node with text after it; no fixture holds a break inside a mark. Guards, one per position, each asserting bytes, the fixed point and that the parsed tree still holds a `break` and no text node containing `&#`: a break as a flanking run's last node before unmarked text (paragraph, and the setext heading), before another mark's run, as the run's first node, two breaks at the edge, on each of the three marks. 2. **should-fix, Required** — `packages/editor/src/schema.ts:787` (`isStrippable`: text that is not `inline_code`) and `:826–866` — the mark-edge clause splits a **link-marked** run at a flanking mark's edge, and the split-off whitespace keeps the `link` mark, so a link whose text has edge whitespace inside emphasis/strong/strikethrough — a tree `parse` produces from valid Markdown — comes back with its text trimmed and a **second, whitespace-only link invented**: `*a [b ](u)* c` → `*a [b](u)*[ ](u) c`; `**a [b ](u)** c` → `**a [b](u)**[ ](u) c`; `x *[ b](u)*` → `x [ *b*](u)`; in a cell `| *[b ](u)* |` → `| [*b*](u) |`. **A regression introduced by 1.30**: at `c9408ee` the same schema left `*a [b ](u)* c` byte-identical (scratch checkout, both runs recorded above). Reproduced on `/dev/editor`: load `*a [b ](u)* c`, type one letter anywhere in the paragraph → pane and copy `*a [b](u)*[ ](u) cx`, "Copied Markdown". Cause: CommonMark's flanking rule reads the character next to the delimiter, which for a link that ends where the mark ends is `)`/`[`, not the whitespace — the whitespace inside the link text is not at a flanking edge at all — but ProseMirror's flat mark set (`[link, emphasis]` on one text node) cannot say whether the link or the emphasis is outermost, and the clause assumes the mark. The task text's own clause ("a link's text keeps its whitespace") is implemented only for a bare link (`editor-fixed-point.test.ts:611`, no flanking mark on the node); the `:629` guard covers the other nesting (`[*b* c](u)`, where the space *must* move within the link) and is right. Fix: in `giveUpEdges`, when the edge node carries `link` and the node beyond the run on that side does not carry the same link (the link's own edge coincides with the run's edge), stop the scan there — the delimiter's neighbour is the bracket, so nothing has to move; keep the `:629` behaviour when the link continues past the run. Guards: `*[b ](u)*`, `*[ b](u)*`, `*a [b ](u)* c` (first, middle, last), the strong and strikethrough twins, the cell, each asserting `format(root)` equals the input's canonical bytes and the parsed tree has exactly one `link`; a corpus leg over every fixture that types a space at the end of every **link-marked** text node (the link is not inclusive, so the leg must `insertText` with the node's marks explicitly, as the mark-edge leg does); a fixture with a link inside emphasis. ## Class-level lessons (for docs/lessons.md)

- LESSON: a backlog deferral written by a fix task on the claim "not reachable by a keystroke while X is unbound" was one Backspace away, because the tree needs no keystroke to *insert* the atom — every loaded file already holds it — and the r2 lesson to probe deletion inside existing formatting before deferring was in the tree when the line was written → a reachability claim in a backlog line names the probe that was run (seed, route, keystrokes, bytes received), and "no keyboard route to insert X" is never taken as "no keyboard route to a tree containing X" when X is in the parser's own output.
- LESSON: ProseMirror's flat mark set cannot say which of two marks on one text node is outermost in the serialised form — `[link, emphasis]("b ")` is one node for `*[b ](u)*` and for the first run of `[*b* c](u)` — so an edge rule stated over "the mark" moved a link's whitespace out of the link and invented a second link → decide an edge rule from the delimiter's actual neighbour in the serialisation (a bracket when the link's edge coincides with the run's, whitespace otherwise), and test every flanking clause with each other mark present on the same node, at both nestings, not only with the flanking mark alone.
- LESSON: `format(parse(out)) === out` accepted `*a\&#xA;*&#x63;` because a backslash-escaped entity is literal text that reparses to itself — the fixed point is necessary and not sufficient for "the user's document survived" → every corpus leg asserts, beside the fixed point, that the output's parsed tree keeps the node kinds the input had (`break` count, `link` count, mark set) and that no text node contains a numeric character reference, with the `&#` check as one regex over the whole family rather than one literal per member found.
- LESSON: a deletion leg that deletes "to the block's end" builds only trees whose atom is the block's last node, and the clause that drops those was the fix under test, so the leg could never reach the atom at a *mark's* end → a destructive corpus leg enumerates its ranges from every container the schema has (the block, the mark run, the link run, the cell), not from the one the finding named.
- LESSON: a same-SHA rerun after a Playwright locator timeout hid whether the hang was the dev server or the app, because the gate fetches artifacts only on success and the classification was written outside the reviewed tree → a gate keeps a failed run's report as evidence too, and a rerun's "transient" verdict is a DECISIONS entry at or before the implementation SHA the reviewers read, or it is quoted into the reconciliation.
- LESSON: a grep cited as evidence that a value is absent from the tree wrote the value into the report that is then committed → evidence that a secret or personal identifier is absent names the pattern's shape, never its literal.
