## Class-level lessons (for docs/lessons.md)

- LESSON: "widen inside a mark's markers" is not the same ownership rule as "widen a text child's encoded edge" — `MARK_MARKER_LENGTH` offsets sit on whatever bytes the inner `containerPhrasing` put there, including a nested leaf's fence or tag — so a guard set that names a code span and an html node must include each as the first and as the last child of a mark, not only as a mid-mark neighbour.
