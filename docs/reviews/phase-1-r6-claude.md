## Class-level lessons (for docs/lessons.md)

- LESSON: a backlog deferral whose trigger is "the task that adds the next X" never fires for a defect inside an X already installed (the r4 autolink line, finding 1) → a deferred serializer class gets one seeded probe per member at the next review attempt (a URL with `\`, `_`, `<`, a trailing `.`), and a trigger names an event the chain can actually produce.
- LESSON: `toRendered ∘ toSource = id` was asserted for the one node class the last finding named, and every other value-bearing inline node and block edge answers "start" (inline code, a cell's end, inline html after a soft break) → the cursor-map family asserts the inverse over every ProseMirror position of every fixture through the editor, and each position class that is not the identity is a named guard, never a doc-comment rule.
- LESSON: an enumeration that claims to be "the whole enumeration" of a third-party function's rewrites is derived from that function's branches (container-phrasing.js has three, not two) and the corpus holds one member per branch; the file's own older test (positions.test.ts:306) already reached the third and nobody read it against the new comment.
- LESSON: "the copied Markdown round-trips" is only meaningful through the app's own `parse`: an extension's `unsafe` escape (`https\://`) can be undone by the same extension's `fromMarkdown` transform, so a copy that a foreign reader shows correctly is still not a fixed point at home → seed the round-trip legs with the text shapes the editor holds as text and the parser would promote (URLs, `www.`), not only with letters.
- LESSON: a principal note written into a task branch's lessons.md mid-chain to drop an acceptance clause is #028's class recurring one chain later → the re-reading is written where #review-1-r5 K3 put it (DECISIONS, under the task), and a lessons line only points to it.
