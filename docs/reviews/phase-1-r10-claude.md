## Class-level lessons (for docs/lessons.md)

- LESSON: an approval retry of a human gate was pointed at the *previous* implementation SHA on the argument that the product files were identical, and the fix task that ran between them changed exactly the serializer the gate's own criterion exercises → a human gate re-taken during a review chain names the SHA it is *re-run against* as a function of the fix tasks still queued, and a gate whose tree is overtaken by a later fix in the same criterion's file is re-taken on the closing tree or its record says in one sentence which criterion it no longer evidences.
- LESSON: a CI attempt was reclassified transient by citing a procedure entry whose third clause ("no runtime file changed between the two SHAs") was false at this gate, and the argument that actually cleared the code — the received bytes were the unchanged seed, so the serializer was never reached — lived only in the failing log → a transient-rerun record restates each clause of its criterion against *this* gate's own diff, and where a clause fails it names the line of the failure log that stands in for it, because "third instance of #023" is a citation, not a check.
- LESSON: a corpus leg that enumerates zero members over the whole index was named in a promote bullet and in the verifier's journal as a discharging test beside a leg with 42 members → a family whose legs are counted from the corpus asserts each leg's member count in the same summary guard that asserts it ran, and the promoting journal entry gives the count beside the title, so an empty leg is read as an empty leg rather than as a discharged clause.
