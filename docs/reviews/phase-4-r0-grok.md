## Class-level lessons (for docs/lessons.md)

- LESSON: a CI / integration validator that appends `--metadata` flags the product `pandoc_args` does not send proves the fixture under a different command than File → Export — the captured artifact can be green while the user's EPUB fails epubcheck → the validator spawn is the product function, or the extra tokens are in `buildPandocArgs` before the first green run.
- LESSON: an acceptance that names a tool "from versions.env" when that file has no pin for it (`unzip -t` in 4.3) stays green on whatever the image and the three CI images already have → the named tool is either a `versions.env` key the Dockerfile and `ci.yml` both read, or the sentence names the apt/image source the way poppler already does.
- LESSON: an architecture tree that lists planned files is not updated when a phase lands a subset of them — `fetch-sidecars.ts` now exists, `assemble-sidecars.ts` exists and is unnamed, `coach-eval.ts` still does not → the first task that creates one of those files rewrites the tree in the same commit, presence and absence.
