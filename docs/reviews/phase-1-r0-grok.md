## Findings (≤ 20, most severe first)

1. **should-fix** — `packages/editor/src/schema.ts:529` — a ProseMirror text node keeps a trailing space (`leafToMdast` copies `node.text` verbatim); `bindProseMirror` commits that tree (`store.ts:170`); `format` (`format.ts:73`) then emits `&#x20;` for a space before a line ending (`mdast-util-to-markdown` unsafe rule). Michael's 1.9 reproduction: character, space, line break → the line above gains `&#x20;`. micromark drops trailing spaces on parse (`format(parse("Hello \n\n- a\n"))` is `Hello\n\n- a\n`), so the corpus never sees this shape; the copied file is not a `format(parse(x))` fixed point. Typora still round-trips; the BBEdit list-rendering claim was not reproduced from the file (DECISIONS #019). Fix: trim trailing ASCII spaces off the last text node of a paragraph/heading in `inlineToMdast` (do not touch a `break` node — that serialises as `\\`); add one test that types `X` + space + Enter and asserts the markdown pane is `X\n\n`, not `X&#x20;\n\n`, plus the absence case (no trailing space → unchanged). Do not weaken the serializer.

## Three riskiest things

1. Finding 1. Every space-then-Enter in the rendered view writes a non-canonical file. `Copy Markdown` (`DevEditor.tsx:186`) is `format` of that tree. The fix belongs on the editor serialize, not on a verify task.

## Class-level lessons (for docs/lessons.md)

- LESSON: a parser that drops trailing spaces and a serializer that escapes them means the editor path and the parse path disagree, and a corpus of `format(parse(x))` fixtures will never see the editor shape → trim at the editor serialize to match what micromark drops, and add one type-space-Enter test; do not change the serializer's unsafe table.
- LESSON: a Playwright spec that asserts computed CSS on probe elements does not prove the highlighter assigned those classes to the document → assert at least one real highlighted node per class the fixture produces, and keep probes only for classes it lacks.
- LESSON: a kitchen-sink editor package (`codemirror`) listed next to the named `@codemirror/*` modules puts history/autocomplete in the lockfile of a package whose source comments exist to keep those modules out → depend on the modules the source imports, and grep the importer for the meta-package name before the verify freeze.
- LESSON: a human observation gate that names a size ("~1,000 words") and validates only that a file exists will ACCEPT a record that never states the size → put the count (or an explicit "not counted") in the payload the reconciliation copies.
