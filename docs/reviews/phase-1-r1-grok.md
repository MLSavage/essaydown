## Findings (≤ 20, most severe first)

1. **should-fix** — `packages/editor/src/store.ts:230-243` — `undoKeymap` (rendered view) still has no test that reads the binding table’s key list, so deleting `KEY_NAMES.redoShiftedLetter` (`Mod-Z`) leaves every rendered-view unit test and every e2e green: `@codemirror/view` / `prosemirror-keymap` fall through to `Shift-Mod-z`, which is bound to the same command. 1.21 recorded the mutation (1836/1838 unit, 59/59 e2e still passed; only `undoKeyBindings`’s `"binds the same three names"` at `store.test.ts:425-428` went red) and left the rendered sibling as a lesson. F9’s class is “assertions that cannot fail”; (a)–(d) shipped, this sibling did not. Fix: add one test next to the source-view one that does `expect(Object.keys(undoKeymap(store)).sort()).toEqual(["Mod-Z","Mod-z","Shift-Mod-z"])` (and the same for the keymap object `storePlugins` installs); a scratch deletion of the `Mod-Z` entry must turn that test red and no other.

2. **should-fix** — `e2e/web/editor-cursor.spec.ts:89` — typing in a paragraph that holds a Markdown soft line break collapses the wrap to a space (`> alpha\n> beta gamma` + caret before `beta` + `X` → `> alpha Xbeta gamma\n`, not `> alpha\n> Xbeta gamma\n`). 1.16 isolated it (`docs/lessons.md` `[1.16]` 2026-09-09T19:22:39Z: reproduced with no source view and no carried cursor, on this code and on the 1.16 branch base; `pmToMdast`/`schema.ts`) and encoded the collapsed pane as the expected string with a comment naming the future line. There is no backlog line. `leafToMdast` (`schema.ts:756-763`) copies `node.text` verbatim, so a `\n` the writing surface does not keep is not a `break` node and is not a parse∘format fixed point of the wrapped source. Fix: represent a soft line break as its own inline node (not a literal `\n` inside a text node), serialise it as a newline not `\\\n`, add a guard test (first/middle/last wrap; absence: a hard `break` still emits `\\\n`), change `:89` to `> alpha\n> Xbeta gamma\n`, and put a corpus leg in `editor-fixed-point.test.ts` that types inside a wrapped paragraph.

3. **nit** — `apps/desktop/src/dev/DevEditor.tsx:206-209` — `copyMarkdown` formats the store without `sourceBinding.current?.flush()`, so a Copy during a source burst copies the last committed snapshot, not the buffer the user is looking at. Toggle and unmount flush (`DevEditor.tsx:102,187-189`); the Phase 1 gate button does not. The markdown pane is the same snapshot, so pane and clipboard agree; they both lag the buffer. Fix: `sourceBinding.current?.flush()` before `format(...)`.

4. **nit** — `e2e/web/editor-clipboard.spec.ts:99` — `expect(checked).toBe(Object.keys(index).length)` is `x === x`: `checked` is incremented in a loop over `names`, which is `Object.keys(index).sort()` (`:31`). The real guards are `mismatches` empty and before/after identity (`:97,92`). Same class as F9(c), which 1.21 just removed from `schema-roundtrip.test.ts`. Fix: collect the names the loop actually loaded and compare that list to `names`, or drop the count assertion.

## Class-level lessons (for docs/lessons.md)

- LESSON: a required finding whose fix task discovers a sibling untested path and records it only in `docs/lessons.md` (1.21: `undoKeymap` vs `undoKeyBindings`) leaves the class open → the discovering task adds the sibling test, or the reconciliation appends it; a lesson line is not a disposition.
- LESSON: an e2e that encodes a known separate defect as the expected pane (`> alpha Xbeta gamma\n`) with a comment naming the future string ratifies the defect unless a backlog line or fix task exists → the comment is a tripwire only when something is scheduled to trip it.
- LESSON: two names bound to one command (`Mod-Z` and `Shift-Mod-z`) make every event-dispatch test, real or synthetic, survive deletion of either name → only a test that reads the binding table’s own key list can prove a name is present (1.21’s mutation, still true of `undoKeymap`).
- LESSON: Grok’s r0 misses of Sol 1/2/4 and Claude 8/10 were visible in the tree without a browser (missing `parseDOM`, raw CM coordinates, empty-cell hull, non-task commit, tautological count); the misses of Sol 3/5 and Claude 2/6/7 needed a probe or a scratch mutation → keep the read-only vantage, and treat spec-vs-tree and test-hygiene holes as in-lane even when the live failure is a browser reproduction.
