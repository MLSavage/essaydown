## Class-level lessons (for docs/lessons.md)

- LESSON: a human observation check whose precondition the build could not produce (no Dock icon, so no Dock Quit) was recorded `not-run`, and the backlog line it was meant to test still reads as confirmed → a gate check that cannot be performed names its missing precondition as an open question in the backlog line it serves, and the next gate that inherits the check states how the precondition is produced.
- LESSON: the shell e2e caret helper (`caretToEndOf`: a click, then `ArrowDown`) reaches a block's end only in a one-block document. After an external reload adds a paragraph, it puts the caret partway into the next line (my probe typed `ExternaZl.`) → any e2e or probe that types after a reload which adds blocks either checks that the caret sits in the intended block or asserts the bytes of the whole file, never only the block it meant to type into.
