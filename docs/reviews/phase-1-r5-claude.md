## Three riskiest things

1. **The whole flanking/encoding chain works on UTF-16 code units, and the corpus is ASCII.** `encode-info.js`, `container-phrasing.js`, `micromark-util-classify-character`, the app's port and `formatWithMap`'s spelling tables all count `charCodeAt` units; the 58 fixtures, the 61,682-transaction r4 sweep and every corpus leg see only BMP text, so a lone-surrogate reference was never on any instrument's path. Finding 1 is the member I found by seeding one emoji; the same class covers any non-BMP letter or symbol at any mark edge, and the position map's offsets across such a character (finding 2's cousin) have no guard either. Until a fixture holds an astral character in every position class the legs enumerate (edge of a mark, neighbour of a mark, inside a link's text, a cell, a heading), the fixed-point property is proven for a subset of Unicode the writer is not confined to.

2. **The position map is a third half nobody owns.** `formatWithMap` instruments the handlers' return values; `containerPhrasing` rewrites bytes after they return (the outside-encoding of J1, and whatever finding 1's fix writes), and every such rewrite silently widens `unresolved`, which the toggle turns into a caret inside the wrong mark. 1.40 pinned the first instance with a hard stop at `1.close`, #026 tried to hand it to 1.43 through a lessons line, #028 withdrew that, and the tree at this SHA still carries the pin — the phase is one planning commit away from closing with a known cursor defect on the toggle path unless the reconciliation takes finding 2.

3. **Mid-chain decisions that live outside the tree.** Three DECISIONS entries and five `chore(…): principal lesson/decision` commits steered the r5 chain; two acceptance clauses were re-read rather than met; the review sees the effects but not the record. The process held (every agent stopped on the conflict, nothing was hidden), but `1.close`'s guarantee — the tree explains itself — is only restored if the reconciliation lands `handoff/023` and says which clause yielded where.

## Class-level lessons (for docs/lessons.md)

- LESSON: a serializer port that classifies and encodes by UTF-16 code unit writes a lone-surrogate reference for any astral neighbour, and an all-ASCII corpus cannot show it → classify and encode by code point (`codePointAt`, `String.fromCodePoint`), and seed every neighbour-class enumeration with one astral member per class (an emoji, a non-BMP letter) beside its ASCII one, because the parser's decoder turns a surrogate reference into U+FFFD silently.
- LESSON: an instrument that maps emissions back to nodes by `indexOf` of the handler's return value misses every rewrite the parent makes afterwards, and the toggle turns each miss into a caret inside the wrong node → a position map learns the parent's rewrites (or re-derives from the final bytes), and its "nothing is unresolved" corpus case is the guard that names which rewrites exist; a new encoding in a handler is a change to that map.
- LESSON: a fix task that discharges a rule by enumeration owns the table's every cell, uncovered ones included — coverage of the new handler's lines is the cheapest check that the enumeration matched the table it claims to mirror → after writing the guards, read the coverage line for the file the fix touched and add the missing cell or say in the doc comment who owns it.
- LESSON: a decision that re-reads a passed-or-running task's acceptance clause, or widens its scope, taken outside a planning commit and recorded on a branch the reviewers cannot see, leaves a tree that cannot explain its own integrations → such a decision lands in the tree before the verifier runs (a planning commit when the graph changes, a DECISIONS entry cherry-picked onto the phase branch when it does not), never a lessons line alone.
