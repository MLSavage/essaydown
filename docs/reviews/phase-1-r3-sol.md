## Findings (≤ 20, most severe first)

Severity, rated by the consequence for the gate's criterion and never by the size of the fix (DECISIONS #review-1-r1): **blocker** — a gate criterion is not met, or wrong output reaches the user silently (example: Copy Markdown puts stale text on the clipboard and reports "Copied"); **should-fix** — a defect or a missing guard the phase should not close with, while the criterion still holds or the path is not the gate's own instrument (example: a redo chord bound under two names with no test that reads the binding table, so deleting one name stays green); **nit** — wording, citations, style, or an assertion with no behaviour behind it (example: `expect(checked).toBe(Object.keys(index).length)` where both sides are the same list). Mark a should-fix **Required** when the reconciliation should fail without it.

Preserve unchanged fixture bytes. Add the browser paste regression and corpus split/join/paste legs with fixed-point assertions, including tight/loose and nested lists.

## Three riskiest things

1. Parser-derived structural attributes can become false after editing even when text normalization is correct. The list paste reaches that class today; inline-only deletion tests do not exercise it.
2. Cursor mapping pairs the live ProseMirror tree with a normalized store tree. Destructive edits and normalization can change that correspondence; current position-map corpus legs only insert text.
3. Deferred source commits take tens of milliseconds and remain a separate authoritative-buffer seam. Phase 2 save/autosave/export consumers must flush before reading and carry action-inside-window tests; current clipboard/history/toggle passes do not prove future readers.

## Class-level lessons (for docs/lessons.md)

- LESSON: A parse-time structural flag can outlive the structure it describes → test editor-originated block splits, joins and multi-paragraph pastes, and normalize derived metadata before serialization.
- LESSON: Promoting a stronger corpus rule while naming only a neighboring family's test leaves the other family unchanged → discharge the rule at every named consumer, including the live cursor map.
- LESSON: An unchanged-output assertion can pass after an action at the wrong location → assert the caret precondition independently before checking normalization.
- LESSON: Starting the browser suite before browser installation finishes creates false failures → finish prerequisite installation before launching dependent tests and retain the failed infrastructure log separately.
