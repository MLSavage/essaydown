Same-mark `*x.*_y_` is a fixed point after 1.67 (journal); the rest of L11's file-load trigger is unchanged.

The bytes of each view still round-trip; the disagreement is visible.

## Class-level lessons (for docs/lessons.md)

- LESSON: a CI attempt labeled transient is a missed key only when the assertion's received value is the pre-keystroke document — `*a.* 😀 *(b)*` against an expected `*a.*&#x1F600; *(b)*` is the seed, so the rerun is not evidence the serializer sometimes skips the astral reference.
- LESSON: a marker switch that requires both "previous sibling is an attention node" and "the bytes already written end in `*`" leaves a nested `***a***` and a literal `\*` on `*`, and it does not exercise two same-mark siblings the editor has already merged — the sweep's emphasis+emphasis cell is one run, and the `~~` twin stays a file-load case.
- LESSON: inserting handlers above `breakSurvivesBeforeHtml` moved its uncovered `return false` from `format.ts:297` to `format.ts:447` without covering it — a backlog line that names a line number is checked by the statement's text, and O2's bridge is still `shift.toEqual(first)` only (`toggle.test.ts:2022`, `position-map-inverse.test.ts:601`), which the pair sweep never reads.
